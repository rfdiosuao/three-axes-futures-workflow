# 三板斧量化方法论（期货）

> 本文是「三板斧」主观量化体系的方法论权威文档，供迁移后的任何环境复现口径。所有参数为经典趋势跟踪惯例，客观可复算；本体系只做数据筛选、信号计算与提示，**不构成投资建议，Agent 一律不自动下单**。

## 一句话

**只做三周期共振方向 + 扳机不响不进 + 破线必走 + 以损定量。**

## 一、第一板斧：选环境（三周期共振）

- 使用月线、周线、日线三个周期，各取最近 10 根 K 线收盘价的简单算术平均（MA10）。
- **多头共振（开多候选）**：月线收盘价 > 月MA10；周线收盘价 > 周MA10 且 周MA10 > 前一期周MA10；日线收盘价 > 日MA10 且 日MA10 > 前一期日MA10。**五项同时成立**。
- **空头共振（开空候选）**：上述全部反向（月线 C<月MA10；周线 C<周MA10 且 周MA10<前值；日线 C<日MA10 且 日MA10<前值）。
- 月线只判断价格在 MA10 哪一侧，**不要求月 MA10 斜率**；等于均线或斜率为 0 一律不满足严格不等式。
- 结果 flat（不共振）或 unknown（数据不足）时**不开新仓**；unknown 不等于 flat，禁止用默认值硬凑。
- 同一品种同一时刻只能持有一个方向，不允许对锁。

### 方向研判（市场温度）

- 统计全部扫描品种的共振方向：市场温度=偏多（多头共振家数多于空头）、偏空、均衡分化。
- **偏多**：市场温度偏多 且 多头共振净差（多−空）≥ 2；
- **偏空**：市场温度偏空 且 净差 ≤ −2；
- 否则为**均衡分化**。

## 二、第二板斧：严格止损（入场即设，不可后移/取消）

- **初始硬止损**：止损距离 = 1.5 × ATR(14)。
  - ATR 口径：TR[t]=max(高−低, |高−前收|, |低−前收|)，取最近 14 根 TR 的简单平均（非 Wilder 平滑），至少需要 15 根日线。
  - 多头止损价 = 开仓价 − 1.5×ATR14；空头止损价 = 开仓价 + 1.5×ATR14。
  - 触及即离场（跳空越过按开盘价成交并记录滑点）。
- **吊灯跟踪止盈**（离场反证位）：近 22 日极值 ∓ 3×ATR(14)。
  - 多头吊灯线 = 近 22 日最低点 − 3×ATR；空头吊灯线 = 近 22 日最高点 + 3×ATR。
  - 突破即离场。跟踪位只向有利方向移动。
- **环境反转退出**：持仓中 T 日收盘后信号不再是所持方向（转反向或 flat），T+1 开盘平仓。
- **日线 MA10 拐头**：作为转弱信号参考（价格站上/跌破日线 MA10 判断环境强弱）。
- 禁止亏损加仓 / 马丁格尔；默认不加仓，一次建满目标手数。

## 三、第三板斧：以损定量（仓位双重约束取小）

账户权益 E（研究/仿真口径 500 万）：

- 风险手数 = floor( E × 1% ÷ (1.5×ATR14 × 合约乘数) )
- 敞口手数 = floor( E × 10% ÷ ( 开仓价 × 合约乘数) )
- **下单手数 = min(风险手数, 敞口手数)**，再与硬安全阀 `max_lots_per_symbol`（默认 300）取小。
- 计算为 0 手则**该品种不交易**（零手=已算但预算不足，区别于 unknown）。
- 组合约束：单品种名义敞口 ≤ 权益 10%；同时持仓品种数上限默认 10；同一板块合计名义敞口 ≤ 权益 20%（高相关品种按同一赛道合并计算）；始终保留现金。
- 合约乘数逐品种读取（roundLot / 交易所参数），禁止统一写死为 10。

## 四、入场扳机（仅在共振方向生效）

1. **突破扳机**：收盘突破近 20 日唐奇安通道高/低点，且当日成交量 ≥ 1.2 倍 20 日均量。
2. **回踩扳机**：价格回踩日线 MA10（容差 0.5%）后重新收阳/收阴，并站回/压回 MA10。

不满足共振方向的品种，扳机一律不生效；扳机不响不进、不追单。

## 五、持仓风险监控分级（第一层扫描）

依据《新手操作与风控手册》：

- 单笔风险预算 = 账户权益的 1%。
- 按相对开仓价累计浮亏：
  - 达预算 50% → 关注（INFO）
  - 达预算 80% → 警告（WARN）
  - 达预算 100%，或逼近不利方向涨跌停（距离 ≤ 3%）→ 危险（DANGER）
- 单品种名义敞口超权益 10% 在简报中标注提示。
- 全部持仓中取最高等级作为组合 LEVEL。

## 六、长假离场压力测试（节前最后交易日盘中 14:35）

- 休市天数与外盘不休/跳空提示；账户权益、可用、保证金、总敞口。
- 组合极端压力：所有持仓节后封不利涨跌停的合计亏损及占权益%、反向跳空 3×ATR 亏损、保证金上调 20% 情景下可用资金。
- 逐持仓灯号：🔴 不建议留 / 🟡 建议减仓 / 🟢 可轻仓留。
  - 🔴：已破位（破吊灯/MA10 拐头）、浮亏 ≥ 预算 80%、单品种封板最坏亏损 ≥ 权益 3% 或跳 3ATR ≥ 权益 2%，任一命中。
  - 🟡：浮亏 50%~80% 或压力接近阈值。
  - 🟢：顺势且压力可承受。
- 节后方向与做多/做空时机 = 三板斧共振方向 + 入场扳机，与日报口径一致；“节后首日跳空不追、扳机不响不进、进场仍按 1% 风险 + 1.5ATR 止损”。

## 七、影子止损守护（SHADOW 纯只读验证）

- 对已登记 1.5×ATR 初始止损的持仓，交易时段每 3 分钟只读扫描。
- 触及登记止损价时：只写本地演练记录 + 发一条「影子演练·未真实下单」飞书，**技术上不包含任何下单调用**。
- 单日累计理论止损浮亏达权益 2% 记录熔断演练；非交易时段/无当日新价不触发。
- 是否切换真实自动平仓，必须由用户二次书面授权后另写执行器。

## 八、证据分级（写报告的边界）

- **行情数值 = 事实**（可核验）。
- **共振/扳机 = 历史规则统计**（相关 ≠ 因果）。
- 本体系**不写**研究假说、新闻、概率或宏观数据；宏观/地缘/财经日历具体数值免费数据无法可靠获取时只给日历链接，禁止编造。
- 报告/文档/看板/消息均保留『不构成投资建议』。

## 九、铁律

- Agent 全程只读：绝不自动下单/平仓/撤单/改单。
- 入场/离场信号是客观触发名单与价位提示，不是买入/卖出推荐。
- 是否交易、何时平仓一律由用户手动决定。
- 文档/消息中不得写入手机号、凭证、open_id。
- 历史规则不代表未来，程序化输出不保证盈利；期货有风险，入市需谨慎。
